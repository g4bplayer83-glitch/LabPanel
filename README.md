# LabPanel

BoneMenu-integrated control panel prototype for BONELAB using BoneLib.

## Features
- Opens a dedicated panel directly from the BoneMenu category (no extra toggle pages).
- Separate pages for **Gravité**, **Vitesse du jeu**, and **Spawn item** with bottom navigation.
- Includes a BoneMenu-native close button (X) and back button (<).

## Notes
- This repo contains only a lightweight code skeleton. Wire up icons and spawn logic as needed.
- The UI is built entirely with BoneMenu APIs so the native cursor/laser interaction is preserved.
